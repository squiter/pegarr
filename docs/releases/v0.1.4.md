# Pegarr v0.1.4

Pegarr v0.1.4 completes the remaining provider and specials work that can be proven safely without performing a live controlled Grab.

## Added

- Pre-add subtitle previews identify fresh versus cached provider evidence and show bounded quota values when the provider reports them.
- OpenSubtitles season searches run as a fallback after insufficient SubDL evidence.
- Only explicit full-season, complete-season, or season-pack release evidence can satisfy a season release; ordinary episode results remain unresolved.
- The provider-settings UI can fill language mappings from the explicit Pegarr subtitle policy as a reviewable starting point, without hardcoding a language or reading Bazarr provider internals.

## Fixed

- Sonarr specials keep season `0` across exact scope selection, SubDL and OpenSubtitles requests, feasibility services, report inputs, and packaged provider probes.
- SubDL provider responses preserve an explicit season-zero value instead of dropping it as absent.

## Verification

- The full release gate covers 304 deterministic automated scenarios.
- Provider errors, ambiguous season results, and missing mapping evidence remain `Unknown`; none are converted to `Not found`.
- The default stays read-only, catalog add keeps automatic search disabled, and no test performs a live Grab.
- The signed release image was deployed at immutable digest `sha256:ce149b54a9536d7c2a488f4749b2e28af6f1996c6988a71619d0c5fb959d51ed`; it became healthy at the exact release revision while the existing login and all six sibling media services remained intact.

## Install

Pin the versioned image in Compose or Portainer:

```yaml
image: ghcr.io/squiter/pegarr:0.1.4
```

Preserve the existing `/data` volume, secret files, and every Arr/Bazarr mount during the update.

## Remaining manual boundary

- A harmless operator-owned controlled Grab and Unknown-outcome reconciliation remain manual and must never be automated against live services.
