# Pegarr v0.1.0

Pegarr v0.1.0 is the first public release of the subtitle-aware Sonarr and Radarr companion.

## Highlights

- Search Sonarr and Radarr catalogs before adding a title.
- Preview title-level subtitle availability from SubDL and OpenSubtitles.
- Configure subtitle policy and provider credentials through the private server-side settings UI.
- Add a series or movie with one explicit action while automatic search is forced off.
- Continue into exact episode, season, or movie release analysis with Arr decisions and subtitle confidence kept separate.
- Compare release candidates locally without repeating upstream searches.
- Keep username/password sessions across container restarts using private hashed state in the persistent data volume.
- Optionally enable administrator-confirmed controlled Grab with revalidation, idempotency, reconciliation, and audit history.
- Run the non-root, read-only container on `linux/amd64` or `linux/arm64`.

## Install

Pin the versioned image in your Compose or Portainer stack:

```yaml
image: ghcr.io/squiter/pegarr:0.1.0
```

Follow the [configuration guide](../configuration.md) for login and integrations, or the [Portainer media-stack runbook](../portainer-jellyfin-stack.md) for an existing same-network Sonarr/Radarr/Bazarr stack. Store credentials in mounted secret files or Pegarr's private server-side settings, never in environment values.

## Safety and known boundaries

- Read-only remains the default. Catalog add and controlled Grab are separate opt-ins.
- Pegarr never automatically chooses or downloads a release.
- Provider failures, timeouts, and quota exhaustion remain Unknown, never Not found.
- OpenSubtitles season-pack search and specials season `0` are not supported in this release.
- Installed NAS acceptance proves Sonarr catalog add without automatic search, exact Sonarr/Bazarr episode analysis, successful SubDL series/movie evidence, quota reporting, cache reuse, restart-safe authentication, and hardened container operation.
- Successful installed OpenSubtitles evidence, installed Radarr add/exact analysis, Bazarr movie assignment, and a harmless operator-owned controlled Grab remain explicit manual boundaries. This release is not described as production-proven for those paths.
