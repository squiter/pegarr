# Pegarr v0.1.1

Pegarr v0.1.1 is a focused display and acceptance patch for the first public release.

## Changed

- Exact analysis displays Bazarr's `pb` language alias as the canonical `pt-BR` label.
- Provider matching, policy filters, and diagnostics retain the original Bazarr policy identity.
- Other language tags use consistent BCP 47-style display casing without introducing a hardcoded user-language default.

## Install

Pin the versioned image in Compose or Portainer:

```yaml
image: ghcr.io/squiter/pegarr:0.1.1
```

Follow the [configuration guide](../configuration.md) for login and integrations, or the [Portainer media-stack runbook](../portainer-jellyfin-stack.md) for an existing same-network Sonarr/Radarr/Bazarr stack. Preserve the existing persistent `/data` volume and every Arr/Bazarr mount during the update.

## Safety and manual boundaries

- `PEG-MANUAL-001`: installed Sonarr exact analysis is proven; installed Radarr exact release analysis remains open.
- `PEG-MANUAL-002`: installed Bazarr series policy resolution is proven; movie-assignment evidence remains open.
- `PEG-MANUAL-003`: hardened NAS startup, persistence, authentication, and SubDL cache reuse are proven; installed Radarr/Bazarr movie evidence and remaining provider-secret permissions stay open.
- `PEG-MANUAL-004`: a harmless operator-owned controlled Grab and Unknown-outcome reconciliation remain manual. Automated release checks never Grab from live services.
- `PEG-MANUAL-006`: a successful OpenSubtitles response, rate evidence, live mapping compatibility, and cache reuse remain open.
- `PEG-MANUAL-007`: installed Sonarr add with automatic search disabled is proven; the equivalent Radarr add remains open.

Read-only remains the default. Catalog add and controlled Grab are independent opt-ins, and Pegarr never automatically chooses or downloads a release.
